Cloud server cho bạn một máy chủ ảo có CPU, RAM, ổ SSD và IP riêng, toàn quyền root để cài phần mềm tuỳ ý. Gói nhỏ nhất từ 98.000đ/tháng (chưa VAT). Bạn mua ngay trên trang, thanh toán QR; chúng tôi kích hoạt máy chủ và có thể cài sẵn website, SSL, tường lửa nếu bạn cần.

Khi nào nên chuyển từ hosting lên cloud server

Hosting chia sẻ đủ cho phần lớn website doanh nghiệp. Bạn nên cân nhắc cloud khi cPanel thường xuyên báo hết CPU, website chậm vào giờ cao điểm dù đã tối ưu, hoặc cần cài phần mềm hosting không cho phép như Docker, Node.js chạy nền, cơ sở dữ liệu riêng.

Cloud server cho người tự làm sản phẩm bằng AI

Ngày càng nhiều người tự dựng ứng dụng bằng Cursor hoặc Claude Code, chạy quy trình tự động bằng n8n, viết bot Telegram, Zalo hay một API nhỏ phục vụ website. Những thứ này cần chạy liên tục 24 giờ, có địa chỉ IP cố định để nhận webhook, và thường không chạy được trên hosting chia sẻ. Một cloud server nhỏ giải quyết đúng việc đó.

Bắt đầu bằng gói nhỏ rồi nâng cấu hình khi cần là cách tiết kiệm nhất: nâng CPU, RAM, ổ cứng không phải cài lại dữ liệu. Khi gửi đơn, ghi rõ bạn định chạy gì, chúng tôi gợi ý hệ điều hành và cách mở cổng phù hợp.

Bảng giá cloud server

Giá trên bảng chưa gồm VAT và cập nhật theo từng thời điểm. Số tiền bạn trả là số hiển thị trong giỏ hàng lúc thanh toán; kỳ hạn 1, 3, 6 hoặc 12 tháng.

Uptime 99,9% nghĩa là gì

Uptime là tỉ lệ thời gian máy chủ hoạt động. Một năm có 8.760 giờ, nên 99,9% cho phép tối đa khoảng 8,8 giờ gián đoạn mỗi năm, còn 99,99% chỉ khoảng 53 phút. Với bot nhận đơn hay API phục vụ khách, nên kết hợp uptime của máy chủ với sao lưu định kỳ và cảnh báo khi dịch vụ ngừng chạy.

  2. Ghi hệ điều hành mong muốn và việc định chạy trên máy chủ.
  3. Quét mã QR để thanh toán.
  4. Chúng tôi kích hoạt máy chủ trong giờ hành chính và gửi email gồm IP, tài khoản root, hướng dẫn đăng nhập.

Câu hỏi thường gặp

Cloud server khác hosting thế nào?

Hosting chia sẻ tài nguyên với nhiều khách và được quản trị sẵn qua cPanel. Cloud server có CPU, RAM riêng và quyền root, cài được phần mềm tuỳ ý như Docker, Node.js hay n8n, nhưng cần người biết quản trị hệ thống hoặc nhờ chúng tôi cài đặt giúp.

Có nâng cấu hình cloud server sau khi dùng được không?

Có. Bạn nâng CPU, RAM, ổ cứng lên gói lớn hơn mà không phải cài lại hệ điều hành hay dữ liệu. Phí nâng tính theo phần chênh lệch cho thời gian còn lại của kỳ hạn đang dùng.

Chạy n8n nên chọn gói cloud nào?

Với vài quy trình chạy theo lịch hoặc theo webhook, Cloud 1 (2 vCPU, 1,5 GB RAM) là điểm bắt đầu hợp lý. Nếu chạy nhiều quy trình cùng lúc, xử lý file lớn hoặc dùng PostgreSQL riêng, chọn Cloud 2 (4 vCPU, 4 GB RAM) để dư bộ nhớ.

Cloud server có IP riêng không?

Có. Mỗi máy chủ có một địa chỉ IPv4 riêng, dùng để trỏ tên miền, nhận webhook từ các nền tảng như Telegram, Zalo, cổng thanh toán, hoặc mở API cho ứng dụng của bạn gọi tới.

Không biết quản trị máy chủ có dùng cloud được không?

Được, nếu nhờ người cài đặt ban đầu. Chúng tôi có thể cài website, SSL, tường lửa và bật sao lưu khi bàn giao. Việc cập nhật phần mềm và xử lý sự cố về sau vẫn cần người theo dõi, hoặc bạn dùng hosting nếu không có ai quản trị.
